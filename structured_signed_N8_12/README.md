## 共通モデル

N=8,9,10,11,12、透過率eta=0.05,0.10,...,1.00の計100条件。
全頂点がセンサであり、補助・参照光子は置かない。

1. |+>^NにCP(phi_ij)=diag(1,1,1,exp(i phi_ij))を作用。
2. 固定局所Cliffordで有効位相軸を選ぶ。
3. 各光子の独立な、偏光に依存しない損失。失われた部分は部分トレース。
4. 生存光子に独立未知位相 exp(-i theta_i Z_i/2) を付与。

損失位置の古典記録を保持し、全損失パターンのQFIMを確率平均する。
推定対象は独立なN位相の算術平均。w=ones(N)/N、
R=1/[N w^T Qbar^+ w]。平均方向が識別不能ならR=0。
生成N光子を分母とし、損失試行も全て含める。独立センサはR=eta。
入力と回転を損失記録に応じて変更しない。設定の確率混合なし。
評価はSLD-QFIMによる分散下限であり、具体的な読み出し測定のCFIは評価していない。

## 1. 条件を満たす符号付き完全二部グラフ

ハブh個・葉m=N-h個。全ハブ–葉間を接続し、部内に辺はない。
全辺は±phi。各ハブの正負の辺数は共通の(a,b)または(b,a)。
グラフ全体で正負の辺数が同数。奇数ハブも許す。

実際に比較した候補：

- 全hについて、符号がs_i*t_jに分解できる対称候補を系統走査。
  正負ハブ・正負葉の個数を比較し、(h_plus-h_minus)*(m_plus-m_minus)=0を課す。
  部内の頂点は最大4つの対称群に分かれる。
- これに加え、条件を満たす一般符号行列をNごとに2初期値抽出。
  これらの各行には(a,b)または(b,a)本の符号をランダム配置する。
- 系統走査はphiを[0,pi]の17点で比較。一般符号初期値は7点で比較。
- 各etaの最良の群対称候補を、近傍で1次元局所精密化。

**先に議論した符号配置の同型類を全件列挙した探索ではありません。**
保存されたsign_matrixまたは群サイズ・符号から、評価した構成を再現できます。

## 2. ハブ間も全接続した構造

h=2,...,N-1。葉を全ハブと正で接続する群r個と、負で接続する群m-r個に分ける。
全ハブ間も接続し、葉間には辺を置かない。

- ハブ–正の葉群：+alpha（0<=alpha<=pi）
- ハブ–負の葉群：-beta（0<=beta<=pi）
- ハブ–ハブ：gamma（-pi<=gamma<=pi）、**正負両方を許す**

alpha,beta,gammaは独立。各ハブの正負の本数はハブ間の辺を含めて同じになる。
全体正負同数・共通絶対重みの制限は、この構造には課さない。
空の葉群も境界候補として許す。重み0の境界では辺が消えるため、保存重みも参照する。

全hとrを比較。各サイズでSobolの8点と24個の手動初期値を評価する。
手動初期値には6・7センサのedge型で見られた重み比と正負のgammaを含む。
各etaの最良サイズ・初期値をPowell法（最大48評価）で局所精密化する。
この連続探索は大域最適性の証明ではない。

## 3. 完全グラフ：群数上限なし

全N(N-1)/2辺が連続変数。N=8〜12で28,36,45,55,66変数。
符号数や絶対重みの一致は課さない。最大群数を制限しない。

- 全辺共通重みの候補を17点走査し、各etaで局所精密化。
- Nごとに2個の初期値について、ランダムな群構造、共通重み0.8と2.6から開始。
  全辺を独立に動かすSPSAを6反復（各反復3評価）行う。
- 追加の1初期値では、N6/N7で保存された1+5、4+2+1、4+1+1、2+2+1+1型の
  重みパターンをNへ拡張し、全辺独立のSPSAを2反復行う。
  小さい群分けは**初期値だけ**で、最適化中に重みを群内・群間で結び付けない。
- SPSAの目的は20透過率の平均対数改善率。評価した全候補を各etaで個別に比較する。
  全辺独立の重みを、各etaについて十分に局所収束させたとの主張はしない。

## 4. 全NセンサのGHZ

正準的なGHZ_N=(|0...0>+|1...1>)/sqrt(2)を、重み最適化なしで比較。
全光子が生存する場合のみ位相情報を与え、R=N*eta^N。

## 回転の探索範囲

- 群対称計算：各群で共通の有効Pauli軸±X,±Y,±Zを全比較。
  群数Gに対して6^G/2配置（全体の符号反転をまとめる）。
- 一般符号・全辺独立計算：構造的な配置と固定seedのランダム配置による有限個の
  **符号なしX/Y/Z配置のカタログ**を比較する。実際の配置は各dense記録に保存。
  その各配置で、全2^(N-1)個の相対符号を比較する。
- 全3^N個の符号なし軸配置を調べるわけではない。
- ゲート代表：+X=H、-X=HZ、+Y=HSdg、-Y=HS、+Z=I、-Z=X（右から作用）。

## 計算方法と検算

engine.pyは置換対称群のDicke基底を用い、群ごとの生存数で損失を集約する。
一般混合状態QFIMのモーメント−支持空間補正の式を使い、零固有空間への結合も含める。
群の一様位相方向と群内位相差が対称性で分離することから、独立位相の平均のQCRBを
群の集合的生成子のQFIMから計算する。独立未知位相を同一と仮定する近似ではない。

dense_engine.pyは各センサ・全損失マスクを個別に扱う低ランク式。
メモリ使用量を抑えるため32マスクずつ処理する。

探索中に候補ごとの独立照合は行わない。最後に各N/etaで選んだ100構成だけを、
validate_winners.pyで再計算する。各損失記録でSLDが支持空間へ作用する行列L_i Uを
独立に作り、Re Tr(rho L_i L_j)を評価する。支持空間から零固有空間への項も含む。
探索のモーメント−補正式とは異なる表式で照合する。

## 再実行

Python 3.10+、NumPy、SciPy、Matplotlib。ここに保存したエンジンだけで実行できる。

```bash
cd structured_signed_N8_12
python -m pip install -r requirements.txt
python unpack_records.py  # 公開済み記録を展開して再利用する場合
python search.py --sensors 8,9,10,11,12 --workers 4 --points 17 --steps 6 --dense-starts 2
python refine.py
python derived_starts.py
python report.py
python validate_winners.py
```

実行済みレコードは再利用する。設定・コードを変える場合は、別の作業コピーでresultsを
空にして実行し、異なる設定の結果を混在させない。refine.pyとderived_starts.pyは既定の
resultsを扱う。乱数seedと軸配置・重みは全レコードに記録する。

results/group_N*.jsonは系統走査、refined_N*.jsonは各etaの局所精密化、
dense_N*.jsonは一般符号・全辺独立の有限予算探索。各レコードのbestには20透過率の
候補が保存される。各etaだけを目的にしていない探索からも、有効候補を共有している。
実行途中のメモリ不足による停止後は、保存済みレコードから再開した。
秒数は各完了ジョブの実測で、総和は並列ワーカー時間であり経過時間ではない。
公開リポジトリでは全679件の実行記録をresults/search_records.json.gzにまとめて保存する。
上のunpack_records.pyで元のJSONファイルを展開できる。新規に計算をやり直す場合は
そのコマンドを省略し、空のresultsを使う。best.jsonのsource_fileはアーカイブ内の名前。

## 結論の限界

構造間の数値比較は、同じ物理モデル・指標で実行可能な候補同士を比較したもの。
ある構造の保存値が低くても、その構造自体が劣ることや未探索の重みで改善しないことを
示してはいない。全符号クラス・全局所Clifford・連続重みの大域最適性、読み出しの
達成可能性、実装コストやゲート誤差は保証していない。
