# グラフ構造・中央測定・局所Cliffordの最適化結果

方法①（同じQFIM候補の重複除去）と方法③（確率的選択のSDP）で最適化した。
中央3量子ビット・センサ3量子ビットの全1,408グラフを評価したところ、最適値は

\[
F_{\mathrm{eff}}^{\mathrm{opt}}=3\eta+6\eta^2
\]

となった。最適構造の一例では、各損失パターンに対して一つの中央基底と、中央の結果に応じた局所Cliffordを選ぶだけでこの値を達成できる。したがって、最終的に提示するプロトコルは確率的な使い分けを必要としない。

## 計算条件

- センサ S1, S2, S3 を伝送し、中央 C1, C2, C3 は保持する。
- 最初に6量子ビット全体のCZグラフ状態を生成する。
- センサの独立な消失を部分トレースで表す。各センサの透過率は同じ \(\eta\)。
- 到着したセンサの集合を、センサを消費せず、中央測定前に把握できる理想条件。
- 位相は損失・中央測定・センサの局所操作の**後**に付与する。
- 位相付与は \(U_i(\phi_i)=\exp[-i\phi_i(I-Z_i)/2]\)。各位相は独立な未知パラメータ。
- 推定対象は全3地点の平均 \((\phi_1+\phi_2+\phi_3)/3\)。
- 中央の各測定はXまたはY。センサの各局所操作は全単一量子ビットCliffordを許す。
- 損失・中央測定結果・選択した設定を記録し、試行を捨てない。
- 総生成光子数は1試行6個。中央で使用する光子も含める。
- グラフは単純無向グラフ。中央同士／センサ同士の役割内の番号交換のみまとめる。局所Clifford同値なグラフを最初から同一視していない。

## 最適値と上限の一致

生存集合を \(S\)、その指示ベクトルを \(u_S\) とすると、各条件のQFIMは

\[
F_S=u_Su_S^T.
\]

損失確率 \(p_S=\eta^{|S|}(1-\eta)^{3-|S|}\) で足し合わせると、

\[
F_{\rm total}=\eta(1-\eta)I_3+\eta^2J_3.
\]

\(w=(1,1,1)^T/3\) として

\[
F_{\rm eff}=\frac1{w^T F_{\rm total}^{-1}w}=3\eta+6\eta^2.
\]

\(\eta=1\) は通常の逆行列が存在しないが、平均方向は識別できるため擬似逆行列で \(F_{\rm eff}=9\)。\(\eta=0\) は情報量0。

この値は、今回の1センサ1量子ビット・各センサ1回の位相付与モデルでの上限でもある。\(e=(1,1,1)^T\) とすると、Cauchy–Schwarz不等式から

\[
F_{\rm eff}\le e^T F_{\rm total}e.
\]

生存数Kの条件で、共通位相の生成子 \(\sum_{i\in S}(I-Z_i)/2\) の固有値幅はKなので、そのQFIは \(K^2\) 以下。損失・中央結果は位相付与前に得られ、確率は位相に依存しないため、

\[
e^T F_{\rm total}e\le\mathbb E[K^2]=3\eta+6\eta^2.
\]

上のグラフと手順は上限を達成する。したがって、単に局所探索で得た良い候補ではなく、モデル内の上限達成プロトコルである。この結論は数値グリッド外を含む \(0\le\eta\le1\) に成立する。

## 資源数を含めた比較

総生成光子数6個で割ると、

\[
\frac{F_{\rm eff}}6=\frac\eta2+\eta^2.
\]

独立な3センサの+プローブは1試行3光子で \(F_{\rm eff}=3\eta\)、1光子当たりは \(\eta\)。この独立プローブとの**同じ総生成光子予算**での比較では、今回の6光子グラフが上回るのは \(\eta>1/2\) である。これは既存のバッファなし適応方式など、すべての比較方式に対する優位性を主張するものではない。

## 方法①と③の実施内容

1. 1,408グラフについて、7つの非空生存集合、8つの中央基底、全非ゼロ中央結果の状態を計算。
2. 全局所Cliffordの効果を符号付きX/Y/Z生成子で列挙し、同じQFIMをまとめた。
3. 同じ損失・中央基底で、全非ゼロ結果の到達可能QFIM集合が一致することを全条件で確認。結果依存のCliffordを選ぶことで、各候補QFIMを全結果で実現できる。
4. 中央基底の確率的選択を許すので、各損失集合で到達可能QFIMの和集合の凸包を使った。1グラフの選択確率は17～48個（誤差の補助変数を足して18～49個）。
5. 生存集合ごとの候補集合がすべて同じグラフもまとめると、1,408グラフは22種類の最適化問題になった。
6. 20透過率（0.05,0.10,...,1.00）について、22×20=440件のSDPを解いた。最良グラフの全操作を再構成した。

最適な候補集合に各生存数の全員GHZのQFIMが含まれるため、最終的には確率的な操作選択が不要になった。

## 検証

- SDP440件はすべて `optimal`。独立に計算した性能上限との最大相対差は \(1.49\times10^{-7}\)。
- 数値解の操作対応表を使って密度行列を実際に変換し、QFIMを再計算。行列の最大差は \(2.78\times10^{-15}\)。
- 代表グラフ246の7生存パターン、全56結果組を直接評価。44個が非ゼロ確率、12個がゼロ確率。
- 全44非ゼロ枝について、複素整数係数と明示的な正規化分母を使い、補正後密度行列が標準GHZ+/+と厳密一致することを確認。
- 0<eta<1の上限を全生存パターンで達成できるグラフは、今回の1,408クラス中58クラス。最小辺数6で、そのクラス数は4。

## 再実行

Python 3.10以降を想定。

```bash
python -m pip install -r requirements.txt
python optimize_graph_sensing.py --output results
python verify_optimal_protocol.py
python make_figures.py
```

透過率を変更する場合：

```bash
python optimize_graph_sensing.py --output results --etas 0.2,0.5,0.7,0.9,1.0
```

`results/candidate_catalog.json.gz` がある場合は、確認済みの候補集合を再利用する。同じ結果ディレクトリで最適化を再実行するとCSV/JSONの結果を更新する。
