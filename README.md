# 完全センサグラフ＋補助葉：センサ4〜10個、補助0〜N個の光子数当たり最適化

センサを完全グラフで接続し、M個の異なるセンサに中央保持の補助光子を1個ずつ付ける。センサ数N=4,…,10の各々について、M=0,…,Nの全56構成を比較した。構造系列を固定し、損失後の中央X/Y測定、結果依存の局所Clifford操作、および記録付きランダム化を最適化する。

評価量は **有効QFI / 総生成光子数 = F_eff/(N+M)**。透過率etaは0〜1を0.001刻みで計算した。構成ごとの56,056行のデータ、透過率ごとの最適値7,007行、精密化した切替境界を収録する。

## 主要結果

この系列内では、低透過率でM=N−1、中透過率でM=N、高透過率でM=0が最適だった。M=1,…,N−2が単独最適になる区間は、今回のN=4,…,10では見つからなかった。これは数値的な比較結果であり、任意のNや全グラフに関する定理ではない。

## 理想モデルと比較範囲

- センサだけが共通透過率etaの独立な消失を受ける。補助光子は中央に保持され、損失しない。
- 生存センサ集合は、センサを消費せず、中央測定前に分かる。
- 位相は損失・中央測定・センサ局所操作の後に付与する。
- 各地点の位相phi_iは独立に未知。U_i=exp[−i phi_i (I−Z_i)/2]、推定対象は全N地点の平均sum(phi_i)/N。
- 損失、中央結果、設定のランダム化の記録をすべて使う。試行を捨てない。
- QFIMを全記録の確率で加算し、w=(1,…,1)/Nに対してF_eff=1/(w^T F^+ w)を評価する。平均方向がFの像にある場合のみ擬似逆行列を用いる。
- 比較は総生成光子予算をそろえる。予算Bの局所QCRBは1/[B F_eff/(N+M)]。
- 読み出し測定のCFI、状態生成成功率、辺の数のコスト、遅延、操作誤差、中央の検出損失は評価していない。
- センサ数Nは各比較の中で固定。Nも変える全資源配分や、他のグラフ構造の最適化ではない。

## 解析的な縮約

補助付きセンサ群Hの大きさをM、補助なし群Uの大きさをq=N−Mとする。

失われたHセンサの補助をX測定すると、損失で残った未知Z作用を識別・補正できる。生存センサの補助はY測定で外せる。Uセンサ全員が到着した枝では、生存完全グラフを局所CliffordでGHZへ変換できる。Uに損失がある枝では、残った未知Zの偶奇による混合があり、2個以上生存なら局所生成子の選択による対角QFIMを得る。単独のHセンサは自身の補助のX測定で純粋化できる。

純粋な生存グラフのQFIM候補は、相関軸を選ぶ部分集合と各符号で記述できる。H/U各群内で置換対称化しても平均位相の精度は悪化しない。方向別の情報量を最大化するには群内の符号をそろえればよく、H/U間の同符号・逆符号の2方策を記録付きで混ぜれば最適な群間相関を実現できる。この縮約を小さい系の全中央X/Y測定・全局所Clifford列挙と照合した。

0<M<Nの最適QFIMは、

\[
F_{ii}=\begin{cases}\eta&i\in H\\d_U&i\in U\end{cases},\quad
F_{ij}=\begin{cases}\eta^{q+2}&i\ne j\in H\\\eta^q&i\ne j\in U\\c_*&i,j\text{が異群}\end{cases}
\]

\[
d_U=\begin{cases}\eta&q=1\\\eta[1-(1-\eta)^{N-1}]&q\ge2\end{cases},\quad
A_H=\eta+(M-1)\eta^{q+2},\quad A_U=d_U+(q-1)\eta^q,
\]

\[
c_* = \min\{\eta^{q+1}, A_H/M, A_U/q\}.
\]

H/U間の符号が同じ方策を選ぶ確率はp_plus=(1+c_*/eta^(q+1))/2。選んだ方策のラベルも記録する。`comparison_N*.csv.gz`を展開したCSVの`cross`と`cross_max`から再現可能。

M=0では

\[
\frac{F_{\rm eff}}N=\eta[1-(1-\eta)^{N-1}]+(N-1)\eta^N.
\]

M=Nではすべての生存パターンで生存GHZを作れ、

\[
F=\eta(1-\eta)I+\eta^2J,\quad F_{\rm eff}=N\eta+N(N-1)\eta^2,\quad
\frac{F_{\rm eff}}{2N}=\frac{\eta[1+(N-1)\eta]}2.
\]

独立プローブはF_eff/N=eta。

## 数値計算と検証

1. 全56構成をeta=0,0.001,…,1で評価（56,056条件）。同率も記録した。
2. 構成曲線の全組の交点を20,001点の網で探索し、符号反転をBrent法で精密化して上側包絡線を作った。有限グリッドと交点探索に基づく数値結果であり、連続区間の最適性を記号的に証明したものではない。
3. **密度行列による独立検証**：N=3,4、M=0,…,N、5透過率で全中央X/Y基底と全局所Clifford生成子を列挙し、SDPと比較。45条件・5,710非ゼロ分岐、最大相対差1.52e−9。
4. **対称化候補のSDP検証**：N=4,…,10、M=1,…,N、5透過率で全符号付き相関部分集合を群対称化して列挙。245条件、最大相対差5.12e−7。この検証は縮約後の最適化を検証するもので、大きい系の全中央測定を密度行列で列挙したものではない。
5. **代数的検証**：560条件でQFIMの半正定値性、行列から直接求めたF_effとの一致、1試行上限、eta=0,1とM=Nの極限を確認。最大相対差1.36e−9。

SDPはCLARABELで解き、`optimal`または`optimal_inaccurate`を受け付けた上で、得られた実行可能な混合から情報量を再計算して解析式と比較した。数値許容差を超えた場合はスクリプトが停止する。

## 再実行

Python 3.10以降。リポジトリのルートから：

```bash
cd auxiliary_optimization
python -m pip install -r requirements.txt
python compare_fixed_graphs.py
python verify_algebra.py
python validate_dense.py
python validate_symmetry_sdp.py
```

主比較だけならnumpy、scipy、matplotlibで実行できる。2つのSDP検証にはcvxpyとclarabelも必要。

```bash
python compare_fixed_graphs.py --grid-step 0.0001 --output results_fine
```

細かいグリッドにするとCSV行数が増える。グリッド間隔は0〜1を等分する最も近い値を使い、実際の間隔をsummary.jsonに記録する。

## ファイル

- `compare_fixed_graphs.py`：解析式、全補助数の比較、交点探索、作図。
- `graph_sensing_core.py`：密度行列、部分トレース、条件付き状態、QFIM。
- `validate_dense.py`：小さい系の全操作列挙による検証。
- `validate_symmetry_sdp.py`：4〜10センサの符号付き相関部分集合SDP検証。
- `verify_algebra.py`：行列と境界の代数的チェック。
- `results/comparison_N4.csv.gz`〜`comparison_N10.csv.gz`：全構成の曲線をセンサ数ごとに圧縮したCSV。Windowsの「すべて展開」またはPythonのgzipで展開可能。再実行時には非圧縮の`comparison.csv`も生成する。
- `results/optimal_by_eta.csv`：透過率ごとの最適M、同率M、独立プローブを含む比較。
- `results/summary.json`：精密な切替境界、代表点、最大利得。
- `results/*validation.json`：今回の検証記録。
- `results/*.png`, `*.svg`：比較図、最適補助数図。

`independent`は補助0個の完全グラフとは別の比較方式。CSVの`best_aux`は常に固定グラフ系列内の最適値であり、独立プローブを含む選択は`best_with_independent`に分けた。
